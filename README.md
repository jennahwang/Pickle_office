# 피클 오피스 · Pixel Office

픽셀 캐릭터가 사무실을 돌아다니는 **개인 할 일 현황판**입니다.
GitHub Pages에서 바로 열리는 정적 페이지이고, 할 일 데이터는 이 저장소에 들어 있지 않습니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `assets/style.css` | 레이아웃·반응형(모바일 바텀시트 / 데스크톱 2단) |
| `assets/app.js` | 픽셀 오피스 렌더러(Canvas), 캐릭터, 할 일 보드, 동기화 |
| `db/Code.gs` | 구글 시트 + Apps Script 웹앱 API 코드 |
| `db/SETUP.md` | 동기화 연결 방법 |

## 동작 방식

- **동기화 없음**: 할 일이 브라우저 `localStorage`에만 저장됩니다. 저장소에는 샘플 항목만 있습니다.
- **동기화 연결**: 화면 오른쪽 위 ⚙ 에서 Apps Script 웹앱 주소와 PIN을 넣으면
  구글 시트에서 할 일을 읽고, 추가·완료·대기·삭제를 시트에 다시 씁니다.
  주소와 PIN은 그 브라우저에만 저장되며 저장소 파일에는 남지 않습니다.

## 맵

- 좌상 · 휴식·커피 코너 (고양이, 커피 머신)
- 중앙 · 할 일 현황판 (대형 스크린)
- 좌하 · 매장 업무 데스크
- 우하 · 일상·위스키 라운지

존을 누르면 그 존의 할 일만 보이고, 단무지 캐릭터가 그쪽으로 걸어갑니다.
바닥을 누르면 그 자리로 이동하고, 캐릭터를 누르면 인사합니다.

## 동기화 연결

1. 페이지 오른쪽 위 **⚙** → Apps Script 웹앱 주소와 PIN을 넣고 저장합니다.
2. 한 번만 열면 연결되는 설정 링크를 쓰려면 주소 뒤에 `#sync=` 를 붙입니다.
   `#sync=` 값은 `{"u":"웹앱 주소","p":"PIN"}` 을 base64url로 인코딩한 것입니다.
   열리면 값은 브라우저에만 저장되고 주소창에서는 사라집니다.

주소와 PIN은 저장소 파일에 들어 있지 않습니다.

## 시트 구조

`tasks` 탭 · `id, title, zone, status, due, note, created, updated`
(`zone`: store / board / life / break, `status`: active / pending / done)
