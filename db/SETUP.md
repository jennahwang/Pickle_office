# 동기화 연결하기 (구글 시트 + Apps Script)

앱은 주소와 PIN 없이도 동작합니다(브라우저에만 저장). 여러 기기에서 같은 할 일을 보려면 아래를 한 번만 준비하세요.

## 1. 시트 만들기
1. <https://sheets.new> 로 새 스프레드시트를 만들고 이름을 `피클 개인 비서실 DB` 로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 편집기의 기본 코드를 지우고 이 폴더의 `Code.gs` 내용을 붙여 넣고 저장(💾)합니다.

## 2. PIN 정하기
1. Apps Script 왼쪽 **프로젝트 설정(⚙)** → **스크립트 속성** → **속성 추가**
2. 속성 이름 `PIN`, 값에 원하는 숫자 4~8자리(예: `4821`)를 넣고 저장합니다.
   - 이 PIN 은 웹페이지 설정에 넣는 열쇠입니다. 다른 사람에게 알려 주지 마세요.

## 3. 시트 탭 준비
1. 편집기 위 함수 선택에서 `setup` 을 고르고 **실행** 을 누릅니다.
2. 처음이면 권한 승인 화면이 뜹니다 → 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**.
3. `tasks` 탭과 머리글 줄이 생기면 성공입니다.

## 4. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙) → **웹 앱**.
2. 설명: `pickle office api`
3. **다음 사용자로 실행: 나**
4. **액세스 권한: 모든 사용자**
5. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 5. 앱에 연결
1. 페이지 오른쪽 위 **⚙** 를 누릅니다.
2. **동기화 주소** 에 4에서 복사한 URL, **접속 PIN** 에 2의 PIN 을 넣고 **저장 후 확인**.
3. "연결됐어요" 가 뜨면 끝입니다. 이후 추가·완료·삭제가 시트에 그대로 기록됩니다.

## 확인
- 브라우저에서 `{웹앱 URL}?pin=4821&action=list` 을 열면 `{"ok":true,"tasks":[...]}` 가 보입니다.
- `{"ok":false,"error":"PIN 이 맞지 않습니다."}` 가 보이면 PIN 을 다시 확인하세요.

## 참고
- 웹앱을 수정한 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다.
- 시트를 직접 편집해도 됩니다. 앱을 새로 열면 시트 내용을 다시 읽습니다.
